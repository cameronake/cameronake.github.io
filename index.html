Projects

Ticket to Ride Bot

A genetic algorithm that evolves Ticket to Ride AI players. Trains a population of strategy-weight vectors through selection, crossover, and mutation across multiple generations; evolved bots outperform the game's built-in opponents.

Live Demo

Bayesian Optimization

Implements Bayesian optimization from scratch using only NumPy. Fits a Gaussian process posterior via an RBF kernel and Cholesky decomposition, then selects the next sample point via Upper Confidence Bound (UCB) or Expected Improvement acquisition functions.

Live Demo

Monte Carlo Options Pricing

Prices European options under both Black-Scholes and Monte Carlo simulation, displaying results side by side. Adjust strike, expiry, and volatility to see how the simulated price distribution and theoretical value respond in real time.

Live Demo

LLM Agent App for Workflow Automation

Built a web application to host custom AI agent workflows for the Fermat R&D team. Integrated the Anthropic API via AWS Bedrock with Gmail, Drive, and Box APIs. Balanced LLM inference with lower-cost algorithmic approaches and designed custom processing pipelines for tasks exceeding the model's capabilities.

Neural Networks from Scratch

Implemented feedforward neural networks and backpropagation from scratch three times across coursework: twice in pure Python with no external libraries (including manual matrix operations), and once with NumPy, trained on MNIST handwritten digit classification. Supported configurable network depth, layer widths, and activation functions.

Augmented Random Forest

Applied skewed probability distributions to the feature-splitting process within individual decision trees, introducing controlled randomness to improve Random Forest ensemble stability.

LSTM Model for Database Automation

Designed and trained a custom LSTM model to predict priority and category labels for M.C. Dean database entries with highly variable formatting and content inconsistencies.
