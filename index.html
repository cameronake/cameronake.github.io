There are always cool problems to be solving at Mudd, and it has a famously challenging curriculum. I love a good challenge, though :) I've maintained a 4.0 GPA even though only 14 people have ever graduated with a 4.0, and even though the freshman/sophomore core classes are usually the GPA-killer classes.

The best part of Mudd is being surrounded by people who are so genuinely excited by everything they do. Mudd is such a collaborative environment that everyone's passion for their work is really contagious. Projects

Ticket to Ride Bot

A genetic algorithm that breeds Ticket to Ride AI players. Evolves a population of strategy-weight vectors through simulated selection, crossover, and mutation across multiple generations. After evolution, bots outperform current best bots.

Live Demo

Bayesian Optimization

Implements Bayesian optimization from scratch using only NumPy. Fits a Gaussian process posterior via RBF kernel and Cholesky decomposition, then selects the next sample point via UCB or Expected Improvement acquisition functions.

Live Demo

Monte Carlo Options Pricing

Prices European options via Black-Scholes and Monte Carlo simulation side by side. Adjust strike, expiry, and volatility to see how the MC distribution and expected price respond in real time.

Live Demo

LLM Agent App for Workflow Automation

Created web app to host custom AI agent workflows for Fermat R&D team, then designed workflows for it. Used Anthropic API via Bedrock, linking to Gmail/Drive/Box APIs. Balanced making LLM calls with using less costly algorithms, then designed custom algorithms to simplify tasks too dense for the LLM.

Neural Networks from Scratch

Implemented feedforward neural networks and backpropagation from scratch three times across coursework: twice in pure Python with no external libraries (including manual matrix operations), and once with NumPy, trained on MNIST handwritten digit classification. Supported configurable network depth, layer widths, and activation functions.

Augmented Random Forest

Applied skewed probability distributions to stabilize the Random Forest algorithm by introducing additional randomness to the splitting of the individual trees.

LSTM Model for Database Automation

Created and fine-tuned custom-architecture LSTM model that predicted priority and category values for messy, unstandardized M.C. Dean database inputs with wild formatting and content inconsistencies.
