# About DOW-bot-results.tsv

Each line of the file is a game executed on Days Of Wonder's mobile Ticket To Ride App, between four copies of the same bot (Vanderbot Jr., Days Of Wonder's best bot for Ticket To Ride's USA board). The bots all behave the same - this is the same bot being pitted against itself in a game, for 50 games (for higher sample size).
