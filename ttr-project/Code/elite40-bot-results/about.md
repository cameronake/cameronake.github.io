# About elite40-bot-results.tsv

Each line is a game played between four copies of the best bot from the `elite40` chain's FINAL population (the bot that scored highest in its final evaluation game, with weights `[5, 0.141, 0.044, 1.479, 0.726, 0.472, 3.051, 0.281, 17.599, 56.452, 0.123, 0.23, 0.454, 0.519, 0.37, -0.284, -0.967, 1.595, 0.496, 27.045, 1.367, 1.179, 26.057, 0.894]`).

All four bots use identical weights; the variation in scores comes purely from random ticket assignment and card draws. 30 games were run.

Columns: `score_1st  score_2nd  score_3rd  score_4th` (tab-separated, sorted descending per game).

Generated by `ttr-project/Code/run_elite40_games.py`.
