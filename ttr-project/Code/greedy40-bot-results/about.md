# About greedy40-bot-results.tsv

Each line is a game played between four copies of the best bot from the `greedy40` chain's FINAL population (the bot that scored highest in its final evaluation game, with weights `[3.177, 0.124, 0.143, 1.821, 0.835, 0.044, 3.568, 0.145, 12.328, 56.201, 0.095, 0.314, -0.678, 0.381, 0.754, -0.554, -0.542, 1.479, 1.651, 26.686, 0.605, 2.291, 20.278, 0.322]`).

All four bots use identical weights; the variation in scores comes purely from random ticket assignment and card draws. 30 games were run.

Columns: `score_1st  score_2nd  score_3rd  score_4th` (tab-separated, sorted descending per game).

Generated by `ttr-project/Code/run_greedy40_games.py`.
